# Thomson Reuters x SpaceXAI

This private Next.js site shows three sample Grok Bot jobs for the Thomson Reuters account team.

## Run locally

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and enter the configured `SITE_PASSWORD`.

## Verify

```bash
npm run verify
npm run typecheck
npm run lint
npm run build
```
